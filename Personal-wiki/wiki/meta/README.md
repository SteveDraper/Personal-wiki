# wiki/meta

**Assistant-maintained** registries—not the main knowledge-article tree.

| File | Role |
|------|------|
| **`concept-aliases.md`** | **Vault-canonical** prose surface form → `[[wiki/concepts/<slug>/…]]` map; optional **Domain** column (see **`AGENTS.md`**). |
| **`domain-registry.md`** | **Vault-canonical** domain slugs, canonical labels, hub paths (see **`AGENTS.md`** → Domains). |
| **`corpus-layout-flarum-jsonapi-export.md`** | On-disk layout for **`flarum_discussions_export.py`** output (e.g. **`raw/planets.flarum/`**, future **`raw/<name>.flarum/`**). |
| **`corpus-layout-donovansvgap-static-export.md`** | On-disk layout for **`donovansvgap_static_export.py`** output (**`raw/donovansvgap/`**). |
| *other* | Optional (e.g. source-quality index) if the vault adopts them. |

No default YAML article frontmatter required here unless a specific file defines its own structure.
