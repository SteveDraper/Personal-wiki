# `_shared` — cross-domain concepts

Notes in **`wiki/concepts/_shared/`** hold **general** or **cross-domain** ideas that are **not** scoped to a single corpus. They use the same article shape as other wiki pages **except**:

- **Do not** set YAML **`domain:`** (omit the key).
- **Filename / `title:`** — Use a **neutral title** without **`(Domain)`** suffix (e.g. `Planet.md` for an astronomy + game abstraction hub), unless disambiguation still needs a qualifier that is **not** a domain label.

When a concept exists both here and under `wiki/concepts/<slug>/`, **narrower** domain pages **link up** to the shared hub per **`AGENTS.md`**.

Details: **`AGENTS.md`**.
