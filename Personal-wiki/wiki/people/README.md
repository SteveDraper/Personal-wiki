# people

**Individual dossiers**—roles, relationships, timelines, and links to **`concepts/`** or **`projects/`**.

## Conventions

- **`type: person`** on each page.
- **One page per person** with **multiple** `raw/` paths in **`sources`** / **`## Sources`** is normal; you do not need a separate wiki page per source document unless you want **`source-summary`** pages for workflow reasons.
- **Frontmatter + `## Sources`**, **attribute** claims, **surface contradictions** when sources disagree about this person.

Details: **`AGENTS.md`** (vault root).
