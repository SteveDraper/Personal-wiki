# projects

**Named work**—goals, milestones, notes, and syntheses for a **deliverable or initiative**.

## Conventions

- **`type: project`** on every page in this folder (unless you consciously choose otherwise and document it).
- Use this when the organizing unit is a **project**, not a timeless theme (those often go in **`concepts/`**) and not a **person** (see **`people/`**).
- **Frontmatter + `## Sources`**, wikilinks to related concepts/people, **atomic** pages where possible.

Details: **`AGENTS.md`** (vault root).
