# Clippings

**Web clips and similar captures** (usually Markdown from Obsidian Web Clipper or similar tools).

This folder lives under **`raw/`**: treat it as **immutable** from the assistant unless you direct otherwise. Paths like `raw/Clippings/your-clip.md` should appear in wiki articles’ **frontmatter `sources`** and **`## Sources`** when those clips support claims.

You may add subfolders (topic, date) if it helps organization.

**Full conventions:** `AGENTS.md` in the vault root.
